# Guided module sample

The companion walkthrough explains how to publish a front end and its API to a static hosting service. Follow it step by step; each folder here maps to one stage of that walkthrough.

## Static hosting starter

The point of this repository is to give learners a base they can build on without starting from an empty folder. Because everyone has a preferred framework, each of the popular ones gets its own folder — pick whichever you are comfortable with.

Every sample uses the same shopping theme so the lessons stay comparable.

## What you should already know

- Comfort with at least one of Angular, React, Svelte or Vue
- Node.js and git installed
- An account on the code host
- An editor of your choice

## What is inside

| folder          | Description                                                                                                   |
| --------------- | ------------------------------------------------------------------------------------------------------------- |
| **angular-app** | A storefront built with Angular |
| **api-starter** | A serverless API skeleton |
| **react-app**   | A storefront built with React |
| **svelte-app**  | A storefront built with Svelte |
| **vue-app**     | A storefront built with Vue |

## Setup checklist

- An account on the code host
- Node.js and git installed
- A code editor installed
- The serverless extension for that editor
- The serverless local runtime
